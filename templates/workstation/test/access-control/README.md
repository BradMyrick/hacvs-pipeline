# test/access-control — privilege enforcement (Stage 8)

Three layers, all matched by `test/access-control/*`:

1. **Declared suite** — hand-written role tests for complex flows (timelock
   delays, role hierarchies, renounce paths).
2. **`GeneratedAccessMatrix.t.sol`** — generated by Stage 8 from the AST;
   asserts every non-PUBLIC state-changing entry point reverts for an
   unprivileged caller. Wire the `TODO_TARGET_CONTRACT` import/upSetup, commit,
   re-run stage 8.
3. **`ManualAccessMatrix.t.sol`** — rows with exotic argument types
   (arrays/structs) land here; name functions
   `matrix_<Contract>_<function>` so the concordance check finds them.
